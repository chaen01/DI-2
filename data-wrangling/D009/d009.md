# 빵셀러 데이터 정제·집계 보고서

## 1. 데이터 개요
- 출처: (가상) 빵셀러 베이커리 체인 운영 로그
- 기간: 2025-04-01 ~ 2025-06-30 (3개월)
- 원본 행 수 / 정제 후 행 수: (  2164 )행 → (  1784 )행

## 2. 발견한 품질 문제
- 결측: revenue 컬럼에서 60건(2.77%) 결측 발견
- 중복: 321건
- 이상치: quantity 컬럼에서 14.56%, revenue 컬럼에서 17.3%
- 표기 혼재: item 컬럼('케이크' vs '케익')

## 3. 처리 결정과 근거 (5줄로)
1. 중복 행 (  321 )건 → 완전히 동일한 행을 제거하여 중복 집계에 따른 매출 과대 계산을 방지
2. store_id 공백 → .str.strip()으로 앞뒤 공백을 제거해 매장 식별값을 통일
3. item '케익' → '케이크' → .replace()로 표기를 통일해 상품별 집계의 정확성을 높임
4. revenue 음수 → 별도 보관 (  1 )건
5. revenue 결측 ( 60  )건 → 제거 (이유: 중복 제거 후 남은 결측 행을 제거해 매출 합계 계산에서 결측값으로 인한 문제 방지)

## 4. 주요 KPI 결과 (2줄)
- (월·매장 관점) 가장 매출이 큰 매장과 그 월: 3개월간 총매출이 가장 높은 매장은 S02 매장으로 총매출이 22,296,500원이고 2025-06이 7,996,500원으로 매출이 가장 높음
